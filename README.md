# EventSphere QA Automation

End-to-end Java automation framework for an event-booking platform.

## Tech stack
Java 17 · TestNG · Rest Assured · Selenium-ready architecture · Maven · GitHub Actions

## Test coverage
- Event search and date filtering
- Seat selection and booking holds
- Payment success and failure paths
- Coupon, cancellation and negative API cases

## Run
```bash
mvn test
```
